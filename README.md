# ⚽ Simulador Liga BetPlay en C#

## 📌 Descripción

Aplicación de consola desarrollada en C# que simula el funcionamiento de la Liga BetPlay, permitiendo gestionar equipos, simular partidos, generar estadísticas y visualizar la tabla de posiciones en tiempo real.

---

## 🎯 Objetivo

Aplicar conceptos de:

* Programación Orientada a Objetos (POO)
* Colecciones en memoria
* LINQ
* Simulación de sistemas
* Persistencia en JSON

---

## ⚙️ Funcionalidades

* Registro de equipos
* Simulación manual y automática de partidos
* Generación de fixture (calendario)
* Tabla de posiciones automática
* Estadísticas avanzadas con LINQ
* Reporte final del torneo
* Persistencia de datos en JSON

---

## 🧠 Tecnologías

* C#
* .NET
* Visual Studio Code
* LINQ
* System.Text.Json

---

## 📊 Ejemplo de uso

* Registrar equipos
* Generar fixture
* Simular jornadas
* Consultar tabla
* Generar reporte final
